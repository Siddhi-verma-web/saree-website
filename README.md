# 🌸 VastraAura – Modern Saree E-Commerce Website

VastraAura is a modern and responsive saree shopping website built using **React, TypeScript, Tailwind CSS, and Vite**. The project provides a clean and elegant shopping experience with beautifully designed product sections, smooth navigation, and a mobile-friendly interface.

## ✨ Features

- 🛍️ Modern E-commerce UI
- 👗 Beautiful Saree Collection
- 🔍 Product Search
- 🛒 Shopping Cart
- ❤️ Wishlist
- 📱 Fully Responsive Design
- ⚡ Fast Performance with Vite
- 🎨 Clean & Elegant Interface
- 🔥 Smooth Navigation
- 💾 Backend Integration using Supabase

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- React Router DOM
- Lucide React

---

## 📂 Project Structure

```
src/
 ├── components/
 ├── pages/
 ├── images/
 ├── lib/
 ├── App.tsx
 └── main.tsx

public/
supabase/
```

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/saree-website.git
```

### Navigate to project folder

```bash
cd saree-website
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```
